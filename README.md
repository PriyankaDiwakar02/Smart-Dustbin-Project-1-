# 🗑️ Smart Dustbin using Arduino

## 📖 Project Overview
This project is an Arduino-based Smart Dustbin that automatically opens its lid when a hand is detected using an ultrasonic sensor. It also monitors the dustbin fill level using a second ultrasonic sensor. When the dustbin becomes full, it provides an alert using a buzzer or LED.

## ✨ Features
- Automatic lid opening and closing
- Touchless operation
- Dust level monitoring
- Full bin alert
- Energy-efficient design

## 🛠️ Hardware Components
- Arduino Uno
- HC-SR04 Ultrasonic Sensor (2)
- SG90 Servo Motor
- Buzzer
- LEDs
- Breadboard
- Jumper Wires

## 💻 Software Used
- Arduino IDE
- Embedded C/C++

## 🚀 Future Scope
- IoT-based monitoring
- Mobile notifications
- Solar-powered operation
